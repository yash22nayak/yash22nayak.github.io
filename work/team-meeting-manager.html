Real-time Extension

Team Meeting Manager

Type

Chrome Extension

Stack

WebSocket · Google Meet API · Laravel

Focus

Live meeting control

Overview

A Chrome extension that gives admins a live control center for Google Meet: scheduling, meeting status and controls, all from a centralized admin panel in the browser.

A persistent WebSocket connection keeps every participant’s status in sync the moment it changes — no polling, no refresh — while the Google Meet API handles session management behind the scenes.

Highlights

  • Live meeting status and controls over WebSocket
  • Centralized admin panel for scheduling
  • Google Meet API integration with a Laravel backend
