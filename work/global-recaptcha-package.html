Overview

An open-source security package that enforces Google reCAPTCHA across all requests of an application - installed once, protected everywhere.

Middleware-based validation with automatic service-provider binding and flexible route configuration means integration takes minutes, not a refactor. Compatible with both Laravel and core PHP.

Highlights

  • Application-wide reCAPTCHA enforcement via middleware
  • Auto service-provider binding, flexible route configuration
  • Works with Laravel and core PHP
  • Published open source
