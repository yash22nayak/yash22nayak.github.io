Stack

Gmail API · Laravel · Encryption

View on Chrome Web Store ↗

Overview

A privacy-focused Chrome extension, published on the Chrome Web Store, that sends encrypted, disposable emails through the Gmail interface people already use.

Messages carry one-time-view logic and are accessible only to verified users. A Laravel backend manages the encryption workflow and exposes secure API flows for controlled message retrieval.

Highlights

  • Encrypted, disposable emails with one-time-view logic
  • Access restricted to verified users
  • Secure API flows for controlled message retrieval
  • Live on the Chrome Web Store
