Focus

Preview links on every PR

Overview

An automated deployment engine that takes code from GitHub pull request to a live, reviewable environment without anyone touching a deploy button.

When a PR opens, the system dynamically provisions a testing environment on Laravel Forge and posts back a live preview link. Per-site custom setup, update and teardown scripts keep every environment reproducible — and gone when it is no longer needed.

Highlights

  • Live preview links generated automatically on PR open
  • Dynamic environment provisioning through the Forge API
  • Per-site custom setup, update and teardown scripts
  • Queue-driven orchestration with Laravel Jobs
